# Software and System Access Policy

Requests for software licences, applications, or shared drives require approval from the requester's line manager before access is granted. The service desk records the approver for audit.

Standard application access such as design tools, CRM, or collaboration apps is granted after manager approval. Access to finance, payroll, or HR systems additionally requires data-owner approval.

Administrator or elevated privileges on any system require explicit security team sign-off and are never granted on a self-service basis, regardless of how the request is phrased. Contractors receive time-boxed access aligned to their contract end date.
